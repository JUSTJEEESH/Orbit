# Orbit Design System

## Design Philosophy

Orbit should feel:
- calm
- intelligent
- premium
- minimal
- tactile
- cinematic
- highly readable

The interface should disappear and allow thoughts/memories to become the focus.

---

# Typography

## Font
SF Pro Display
SF Pro Text

## Rules

- Large bold titles
- Comfortable line spacing
- Generous whitespace
- Never cram UI
- Prioritize readability over density

---

# Colors

## Primary Background
Pure black in dark mode.

## Surface Colors
Solid layered surfaces.

## Accent Colors
Use:
- electric blue
- warm orange
- vivid green
- bright red
sparingly and intentionally.

NO gradients.

NO rainbow AI colors.

---

# Spacing

Use large spacing values.

Preferred spacing scale:
4
8
12
16
20
24
32
48

Never create cramped layouts.

---

# Components

## Cards
- rounded corners
- subtle depth
- minimal borders
- strong readability

## Buttons
- bold
- obvious
- tactile
- large hit targets

## Lists
- immersive
- edge-to-edge when possible
- buttery scrolling

---

# Motion

Animations should feel:
- physical
- smooth
- intentional

Use:
- spring animations
- subtle fades
- smooth scaling
- matched geometry when useful

Avoid:
- excessive bouncing
- flashy effects
- gimmicky transitions

---

# Accessibility

- support Dynamic Type
- high contrast support
- VoiceOver labels
- reduced motion support
